# 📊 Student Social Media, Wellbeing & Academic Impact Analysis — Power BI

## 📌 Project Overview

This project uses **Power BI** to analyze social media usage among **705 students aged 18–24** and explore patterns related to academic impact, sleep, mental-health indicators, addiction score, platform usage, demographics, and relationship status.

The project goes beyond dashboard creation by combining **data analysis, interactive reporting, segmentation, drill-through analysis, and stakeholder-focused interpretation**.

> **Important:** The analysis is observational and based on self-reported data. The findings describe patterns in the dataset and do not establish medical or causal relationships.

---

## 🎯 Business / Stakeholder Objectives

The dashboard was designed to answer questions such as:

- How large is the student population being analyzed?
- How much social media are students using on average?
- Do students report an academic impact from social media?
- Which age and academic-level groups have higher usage?
- Which social media platforms have the largest student reach?
- How does sleep vary across age groups?
- Do usage patterns differ by gender?
- How does relationship status relate to conflict levels?
- Can stakeholders drill into individual student-level records?
